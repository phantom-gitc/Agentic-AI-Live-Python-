# Prompting Examples

Use direct, outcome-focused prompts:

```text
Analyze this project and tell me the main folders and entry points.
```

```text
Create a FastAPI app with one health endpoint and run it locally.
```

```text
Review this project for security issues. Do not edit files.
```

```text
Run the tests and fix any failures.
```

```text
Build a clean CLI todo app with add, list, done, and delete commands.
```

For safer runs, add constraints:

```text
Inspect only. Do not edit files.
```

```text
Make the smallest possible change and run verification.
```

```text
Do not install new dependencies unless absolutely required.
```
